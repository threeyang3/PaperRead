# 首批具身智能与触觉论文样本

这批样本不是线性学习路径，也不是论文排名。它是一组用于验证 PaperFlow
抓取、AI 分析、图片提取、本地投影、Feed 发布和订阅同步的覆盖性测试集。
机器可读清单位于
`examples/representative-embodied-ai-papers.yaml`。

## 选择原则

- 以 arXiv 原始记录作为稳定来源；
- “近些年”是主体，但对开创性工作保留 2017–2021 年的必要例外；
- 每篇论文标注为开创性、代表性或前沿样本，避免把“新”误写成“开创”；
- 各方向相互独立，不把设置 Agent、抓取、分析或研究方向排列成前后继关系；
- 触觉获得额外权重，同时保留导航、运动、世界模型、语言规划、模仿学习和 VLA；
- 论文标题、图注、摘要等原文不做机械翻译。

## 为什么没有只选“最新论文”

只选最近论文无法验证系统是否能处理不同年代的 arXiv 元数据、PDF 排版、
图注格式和版本历史，也会遗漏一个方向真正改变研究范式的论文。因此样本同时
包含领域起点、形成期代表作、开放基线和当前前沿。

## 预期验收

每篇论文都应具有：

1. arXiv Raw 元数据和本地 PDF；
2. 可追溯的完整 AI 分析身份；
3. 中文界面下的中文解释结构，但保留论文原文；
4. 有可靠图注时生成本地视觉导读；
5. 可重建的 Markdown、Derived 记录和 User sidecar；
6. 可发布的 Raw/AI Feed 记录，且无 User Data、PDF 或本地路径；
7. 从 GitHub Feed 订阅回读后通过信任策略和 schema 校验。

## 2026-07-19 实测结果

- 26 篇完成 Codex `gpt-5.4` 结构化分析，π0、FAST、π0.5 三篇完成
  Claude Code `mimo-v2.5` 结构化分析；
- 29/29 篇生成视觉导读，共 166 张可追溯图片，每篇 3–6 张；
- Obsidian “视觉浏览”返回 29 张卡片，“触觉论文”提供独立子集入口；
- 独立 `ArXiv-data` Feed 包含 29 个 Raw 与 29 个 AI 记录，不包含 PDF、
  User Data 或渲染笔记；
- GitHub 回读 dry-run 预计创建 58 个记录，实际同步结果相同；
- 第二次同步创建 0 个记录、复用 58 个记录，冲突为 0；
- 同步全过程 `user_records_modified=0`、`remote_code_executed=false`；
- Windows `core.autocrlf=true` clone 后的 checksum 回归测试通过。
