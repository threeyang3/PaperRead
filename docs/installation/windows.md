# Windows installation

Use Python 3.11+, `pipx install paperflow`, `uv tool install paperflow`, or
`scripts/install.ps1`. The Windows portable archive includes an installer,
uninstaller, launcher, wheel/source, schemas, migrations, prompts, templates,
Obsidian integration bundles, user/maintainer documentation, example
configuration, version, and checksums. The separate Template Vault archive
contains only the curated skeleton and plugin configuration. Neither archive
contains papers, PDFs, user notes, runtime state, or AI credentials.
